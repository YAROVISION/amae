# Дизайн-система: Газетно-інженерний ретро-бруталізм (Technical Editorial)

Цей документ описує стилістику та правила побудови інтерфейсу, вилучені та формалізовані на основі файлу `style.css`. Стиль поєднує швейцарську газетну верстку (editorial/broadsheet), естетику аналогової технічної документації, чеків і ретро-терміналів.

---

## 1. Загальна концепція та філософія

* **Естетика:** Друковане видання, вінтажний щоденник / таблоїд, технічний звіт, інженерний чек.
* **Ключові риси:**
  * Чіткі контрастні розділювальні лінії замість розмитих тіней.
  * Виразний контраст між надвеликими масивними заголовками та дрібним моноширинним текстом.
  * Теплий паперовий фон (`--paper`) та глибокий «друкарський» графітовий колір тексту (`--ink`).
  * Функціональні акценти (теракотовий, приглушений синій, хвойний зелений).
  * Таблична, сіткова структура контенту (Grid / Border-based layout).

## 3. Типографіка

### Шрифтові гарнітури
* **Дисплейний (Display / Headings):** `"Barlow Condensed", "Arial Narrow", Impact, sans-serif`
  * Використовується для: H1, H2, великих числових показників, кнопок вибору, годинників/таймерів.
  * Стиль: надвузький (Condensed), наджирний (600, 700, 800), переважно `text-transform: uppercase`.
* **Моноширинний (Body & Data):** `"DM Mono", monospace`
  * Використовується для: основного тексту, таймштампів, підписів, системних повідомлень, міток, навігації.
  * Стиль: технічний, компактний (10px – 13px), line-height: 1.5.

### Ієрархія розмірів

| Елемент | Шрифт | Розмір / Line-height | Letter-spacing / Регістр |
| :--- | :--- | :--- | :--- |
| **Hero Title (H1)** | Display (800) | `clamp(64px, 8.5vw, 150px) / 0.81` | `-0.045em`, UPPERCASE |
| **Годинник / Таймер** | Display (700) | `74px / 1` (моб: `60px`) | `-0.025em`, `tabular-nums` |
| **KPI / Totals / Issue** | Display (700) | `clamp(36px, 4vw, 56px) / 1` | `tabular-nums` |
| **Секційні заголовки (H2)**| Display (700) | `27px / 1` | UPPERCASE |
| **Заголовки карток / блоків**| Display (600) | `25px – 26px / 1` | Normal / UPPERCASE |
| **Основний текст (Body)** | Mono (400) | `13px / 1.5` | Normal |
| **Таблиці / Списки логів**| Mono (400) | `11px` | Normal |
| **Етикетки (Eyebrow / Meta)**| Mono (500) | `9px – 10px` | `0.06em – 0.1em`, UPPERCASE |

## 4. Сітка, відступи та геометрія

* **Базовий контейнер:** `max-width: 1440px`, центрування через `margin: auto`, адаптивні бокові поля `5vw` (на великих екранах 60px, на мобільних 16–20px).
* **Стиль кордонів (Borders):**
  * Замість відступів-порожнеч структура задається суцільними лініями:
    * Основні роздільники: `1px solid var(--ink)` або `2px / 3px solid var(--ink)`.
    * Внутрішні клітинки: `1px solid var(--line)`.
    * Перфорація / відривні елементи (квитанція): `2px dashed var(--ink)`.
* **Закруглення (Border-radius):** **0px** (повністю відсутні, всі кути суворо прямокутні).
* **Тіні (Box-shadow):**
  * М'які розмиті тіні не використовуються.
  * Допустима жорстка ретро-тінь зі зміщенням без розмиття: `box-shadow: 3px 3px 0 #cbc6b7;`.

## 5. Компоненти інтерфейсу

### 5.1. Мастхед / Шапка видання (`.masthead`)
* Тонка верхня плашка з двома лініями (верхня жирна `5px`, нижня тонка `1px`).
* Текст у верхньому регістрі, розмір `10px`, збільшений міжлітерний інтервал (`letter-spacing: 0.09em`).

### 5.2. Інтерактивні картки завдань / вибору (`.quest`)
* Складова сітки `grid-template-columns: repeat(N, 1fr)`.
* Розділяються тонкими лініями (`border-right: 1px solid var(--line)`).
* При наведенні плавно змінюють фон на `#dedcc9`.
* Всередині містять: категорію/ціну з моноширинним шрифтом, велику дисплейну назву та компактний моноширинний опис.

### 5.3. Кнопки та дії (`.finish`, `.random`, `.sample`)
* **Solid Button (`.finish`):** фон `var(--ink)`, текст `var(--paper)`, чітка рамка `1px solid var(--ink)`.
* **Outline Button (`.random`):** прозорий фон, рамка `1px solid var(--ink)`.
* **Accent Sample (`.sample`):** фон `#486789`, жорстка пласка тінь `3px 3px 0 #cbc6b7`. При успіху переходить у `var(--orange)`.
* **Focus State:** `outline: 3px solid var(--orange); outline-offset: 5px;`.

### 5.4. Графіки та шкали прогресу (`.chart`, `.track`, `.bar`)
* Горизонтальні графіки-смуги з підкладкою у вигляді штрихованої міліметрівки:
  `repeating-linear-gradient(to right, transparent 0, transparent calc(25% - 1px), var(--line) calc(25% - 1px), var(--line) 25%)`.
* Анімація заповнення: плавна крива `cubic-bezier(0.2, 0.7, 0.3, 1)`.

### 5.5. Штамп (`.stamp`)
* Декоративний або статусифікуючий елемент.
* Рамка `2px solid currentColor`, колір `var(--orange)`, нахил `transform: rotate(-5deg);`, капслок.

### 5.6. Квитанція / Чек (`.receipt`)
* Фон темніший за основний (`#e6e2cf`).
* Верхня та нижня межа — перфорація `2px dashed var(--ink)`.

### 5.7. Стрічка логу / Подій (`.log`)
* Моноширинний список подій із виділеними помаранчевими датами/таймштампами (`9px`) та тонкими розділювачами.

---

## 6. Адаптивність (Mobile Patterns)

* **До 950px:**
  * Сітка робочої області та панелі звужується, картки перегруповуються в меншу кількість колонок.
* **До 650px (Mobile-first адаптація):**
  * Картки меню трансформуються в горизонтальну стрічку з плавною прокруткою (`grid-auto-flow: column`, `scroll-snap-type: inline mandatory`).
  * Панель дій стає закріпленою знизу (Fixed bottom bar) з ефектом матового скла (`backdrop-filter: blur(10px)` та напівпрозорим фоном).
  * Дисплейні заголовки плавно зменшуються через `clamp()`.

---

## 7. Доступність (Accessibility & Motion)

* Підтримка `prefers-reduced-motion: reduce`: повне вимкнення анімацій, плавного скролу та переходів для чутливих користувачів.
* Яскраві контрастні стани `:focus-visible` з обов'язковим офсетом.
* Використання властивості `tabular-nums` для цифр у таймерах та сумах задля уникнення стрибків верстки.
